# UI 设计说明（ui-notes）

> 面向贡献者的界面设计档案：元素、交互决策与其理由。

## 布局

三栏宽屏：左（扩展名）/ 中（结果虚拟列表）/ 右（预览），顶部输入条 +
可折叠选项条，底部四段状态栏（进度条 / 文件计数 / 索引状态 / 状态文本）。
三栏宽度可拖拽，折叠状态与列宽随窗口退出记忆。

## 关键交互决策（为什么这么做）

| 决策 | 理由 |
|------|------|
| 结果虚拟列表（LVS_OWNERDATA） | 命中可达 10 万条，不一次性物化 |
| 默认按路径排序 + 列头点击切换 | 找得到重点；新搜索复位 |
| 双击 → 预览定位到命中行 + 全文标黄 | 「搜到 → 看上下文」一步完成；标黄上限 1000 处防病态长文 |
| 预览定位用闭环反馈滚动 | riched20 的滚动位/度量是惰性的，开环定位（像素/行基/状态机）均被异步重排打偏；反馈式「读视口差 → 修正 → 再读」对任意滚动状态成立。内容装得下视口时不滚动（防孤儿位移：滚进滚动条无法表达的区间后鼠标无法返回） |
| 预览行号按真实行编号 | 自动换行仅是显示折行，折行续行不显示行号——行号永远等于文件真实行号（用户明确的语义铁律） |
| 悬停预览时滚轮直接滚动预览 | 双击后焦点留在结果列表，Windows 把滚轮发给焦点窗口——不转发则预览永远滚不动 |
| 右键「打开编辑」 | 无默认关联时自动回退记事本（本工具只针对文本型文件） |
| 导出按钮随结果集启用/禁用 | 比点击后报错更早给反馈 |
| 看门狗（60s 无进度询问取消） | 索引模式只有头尾两个进度点，不弹误报 |
| 关窗时建库确认 | 建库无法中断，等待前明确告知 |

## 可配置项（INI）

结果上限 / 单文件正则超时 / 看门狗秒数 / 历史条数 / 预览上下文行数 /
标黄上限 / 大文件预览阈值与上下文窗口 / 界面语言——全部在
`%LOCALAPPDATA%\TextSearch\textsearch.ini`（`[Search]` / `[Preview]` /
`[Window]`），每个键都有文档化默认值（见 `core/config.cpp`）。

## 多语言

文案经 `i18n::tr()/trf()` 取自 `core/i18n.cpp` 内嵌表（zh 基线 + en），
缺失回退中文、无条目回退 id。加语言 = 在表中加一列 + ini 选语言（重启生效）。
